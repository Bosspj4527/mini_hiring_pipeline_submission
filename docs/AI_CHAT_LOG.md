# AI Chat / Development Log

This file documents the AI-assisted reasoning used for the take-home implementation. It is intentionally a concise engineering log rather than a claim that every line of code was generated by AI.

## Prompt 1 — Architecture
**Prompt:** Build a small recruiter hiring pipeline with immutable history, one-step stage movement, terminal rejection/hire outcomes, and a natural-language search box.

**AI response summary:** Suggested a small Python web application, relational persistence, an append-only history table, and a deterministic query parser before adding any AI/LLM query interpretation.

**Decision:** Used FastAPI + SQLAlchemy + SQLite + Jinja2 because the assignment is small and the stack keeps the runtime and deployment surface simple.

## Prompt 2 — Search
**Prompt:** Support typo-tolerant names, stage queries, time-in-stage queries, "since Monday", offer-not-hired, and combined filters.

**AI response summary:** Suggested using a fuzzy-matching package such as RapidFuzz and a structured parser that converts natural language into filters.

**Disagreement:** I did **not** use a fuzzy-matching package. I chose Python's standard-library `difflib` instead. For this small dataset it removes an external dependency and keeps the matching logic transparent and easy to test. If the dataset became large, I would revisit this decision.

## Prompt 3 — Audit trail
**Prompt:** Ensure history cannot be edited after it is recorded.

**AI response summary:** Suggested an append-only history entity and no edit/delete UI.

**Decision:** Added ORM-level update/delete guards on `StageHistory`, and all state changes create a new history row in the same database transaction.

## Human verification checklist
- Verify forward movement is exactly one stage.
- Verify Hired and Rejected cannot be changed.
- Verify every transition creates a history record.
- Verify search returns a helpful error instead of silently returning an unexplained empty result.
- Verify typo search ranks the intended candidate first.
